fast-ccsds-parser は、宇宙業界の通信規格「CCSDSスペースパケット」を Pythonで高速に解析するライブラリです。衛星から届いたバイナリデータを パケットごとに切り分け、ヘッダとペイロードをすぐ扱えるかたちにします。

fast-ccsds-parser is a Python library for CCSDS Space Packets, the telemetry standard used across the space industry. It splits raw binary dumps into packets and hands you clean headers and payloads.

$ pip install fast-ccsds-parser
PyPI GitHub

何をしてくれるの？

What does it do?

人工衛星は、温度や電池の残量、撮影した画像などの情報を小さな「小包（パケット）」に 分けて、次々と地上へ送ってきます。届いたままのデータは数字が並んでいるだけで、 どこが1つの小包の区切りなのか人には読めません。このライブラリは郵便局の仕分け係のように、 小包の区切りを見つけ、荷札を読み、中身を取り出します。

Satellites send their data (temperatures, battery levels, images) as a stream of small "parcels" called packets. As received, it is just a wall of bytes. This library works like a mail sorter: it finds where each parcel starts and ends, reads its label, and unpacks the contents.

ヘッダ解析

Header parsing

6バイトのプライマリヘッダから、バージョン、APID、シーケンス番号、パケット長などを取り出します。

Decodes the 6-byte primary header: version, APID, sequence flags and count, packet length.

✂️

ペイロード分離

Payload extraction

ヘッダの長さ情報をもとに、データ本体を正確に切り出します。間違えやすい「長さ − 1」の扱いも内部で処理します。

Slices each data field exactly, handling the error-prone "length minus one" rule for you.

使い方

Usage

数行で、ダンプファイルのパケットを順番に取り出せます。

A few lines walk every packet in a dump file.

from fast_ccsds_parser import iter_file, parse_primary_header

# ヘッダだけを dict で / Just one header, as a dict
parse_primary_header(raw_bytes)
# {'version': 0, 'type': 0, 'secondary_header_flag': 1, 'apid': 42,
#  'sequence_flags': 3, 'sequence_count': 1337, 'packet_length': 255}

# ダンプファイルを1パケットずつ / Stream a whole dump, packet by packet
for pkt in iter_file("groundstation_dump.bin"):
    print(pkt.header.apid, pkt.header.sequence_count, len(pkt.payload))

ほかのツールとの使い分け

How it fits with other tools

CCSDSパケットを扱うPythonライブラリには、成熟したものがすでにいくつもあります。 どれもパケットの分割やヘッダの読み取りができるので、目的に合わせて選んでください。

Several mature Python libraries already handle CCSDS packets, and all of them can split packets and read headers. Pick the one that fits your job.

ccsdspy

パケット定義に従って、中身の値（温度や電圧など）までデコードしたいとき。NASAのミッションでの実績があります。

Decode packet contents (temperatures, voltages) from packet definitions. Used on NASA missions.

space_packet_parser

XTCE形式のパケット定義でデコードしたいとき。ソケット入力や分割パケットの結合にも対応しています。

Decode with XTCE packet definitions. Also reads sockets and reassembles segmented packets.

spacepackets

ECSS PUSやCFDPのパケットを作成・解析したいとき。Rust版もあります。

Build and parse ECSS PUS and CFDP packets. A Rust version is also available.

fast-ccsds-parser

大きなダンプやリアルタイムのデータを、少ないメモリですばやく分析ツールに渡したいとき。依存ライブラリはありません。

Get large dumps and live streams into analysis tools quickly, with little memory and no dependencies.

速度とメモリ使用量の比較は README に載せています。計測に使ったスクリプトもリポジトリにあります。

Speed and memory comparisons are in the README, with the benchmark script in the repository.

ロードマップ

Roadmap

Python APIはそのままに、段階的に機能と速度を高めていきます。

The Python API stays stable while features and speed grow.

  1. ✓ Phase 1

    Pure Python プロトタイプ（v0.1.0、公開済み）
    ヘッダ解析、パケット分割、ペイロード分離、ファイルのストリーム処理。

    Pure-Python prototype (v0.1.0, released)
    Header parsing, packet splitting, payload extraction, streaming file parsing.

  2. → Phase 2a

    表形式での出力
    to_arrow()・to_polars()・to_pandas()。データを列ごとにまとめて持ち、メモリ使用量を入力ファイルの大きさに近く保ちます。

    Columnar output
    to_arrow(), to_polars(), to_pandas(), keeping memory close to the input size.

  3. → Phase 2b

    時刻の解析
    セカンダリヘッダに入っているCCSDS時刻コード（CUC・CDS）をタイムスタンプに変換します。

    Time codes
    Decode CCSDS time codes (CUC / CDS) in secondary headers into timestamps.

  4. → Phase 2c

    リアルタイム受信
    TCPソケットやWebSocketから届くデータを、非同期（asyncio）で届いたそばから解析します。

    Live streams
    asyncio parsing of live TCP socket and WebSocket streams.

  5. ⚡ Phase 3

    高速化
    ベンチマークで遅いと分かった処理をRust（PyO3）に置き換えます。Pythonからの使い方は変わりません。

    Speed
    Move the hot loops that benchmarks show are slow to Rust (PyO3), keeping the Python API unchanged.
